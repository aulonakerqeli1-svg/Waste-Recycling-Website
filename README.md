🌿 Waste Recycling Website
Waste Recycling Website is an informative site designed to educate users about different types of waste, the recycling process, and ways to contact organizations promoting recycling. This project is perfect for showcasing skills in HTML, CSS, and responsive web design.

📌 Key Features
Responsive Navbar: Hamburger menu for mobile devices.
Waste Types Section: Interactive cards showing main waste categories (Plastic, Paper & Cardboard, Organic, Metal, E-Waste, Hazardous).
Recycling Process Section: Embedded educational video from YouTube with process description.
Contact Form: Form to send messages along with visible contact information.
Responsive Design: Optimized for desktop, tablet, and mobile screens.

💻 Technologies Used
HTML5
CSS3
JavaScript (for the hamburger menu)
